# 🌈 兒童數學美工繪本與教案專案 (Elementary Math Pixar Curriculum)

本專案提供一套專為 **小學低年級與幼稚園大班 (5-8 歲)** 設計的兒童數學數感教案與美工繪本電子書，改編自 **Stanford Youcubed** 經典數學教學理念。

---

## 🎨 專案特色

1. **100% 皮克斯 (Pixar 3D) 童話繪本首頁視覺**：
   - 每個單元均配備吸睛的擬人化小動物角色故事插圖，極大激發學生的學習興趣與好奇心。
2. **教具實作美工圖解**：
   - 配有高彩度教具操作圖解（卡扣積木、十格陣、天平、數線跳躍、保齡球等）。
3. **詳細教學步驟與數學查核**：
   - 經過嚴格的數學正確性查核，並包含老師/家長引導的四步驟實作流程。
4. **自動化美工繪本 SOP Skill**：
   - 內建 `pixar-storybook-math-art` Skill 規範說明與 PDF 自動化繪本編譯腳本。

---

## 📂 目錄結構

- `curriculum/K_Term1/`：20 個單元的繁體中文詳細 Markdown 教案檔。
- `generated_art/`：教具與美工圖解庫。
- `PIXAR_STORYBOOK_MATH_ART_SKILL.md`：兒童數學美工繪本設計 SOP 文件。
- `Elementary_Math_Curriculum_Pixar_Storybook_Master.pdf`：全套 20 單元彩色繪本電子書 PDF。
